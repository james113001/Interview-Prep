Coding practice from LeetCode (LC), Hackerrank (HR), and ByteByteGo (BBG)

Organized by topic/pattern, one folder per pattern. Some topics have sub-pattern folders
(e.g. `Linked Lists/Fast Slow Pointers`, `SQL/Advanced Join`). SQL problems live under `SQL/`;
everything else is Python.

File naming: `<Problem Name> <Source> <Difficulty>.py` (LeetCode files keep their site-assigned
number prefix, e.g. `2. Add Two Numbers LC Medium.py`).
